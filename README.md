# Leetcode.learn
Leetcode前端题目解题学习(JS)
 🎯 项目简介
本仓库是我作为前端开发者，系统刷 LeetCode 算法题的学习记录。所有题目均使用 JavaScript 实现，重点聚焦前端面试高频考点，旨在提升算法思维与代码能力，为前端岗位面试夯实基础。
✨ 核心内容
分类刷题：按「数组/字符串/哈希表/双指针」等高频标签整理，覆盖前端面试 80% 以上的算法考点
多解法对比：每道题提供「暴力解法」与「最优解法」（如哈希表），并分析时间/空间复杂度
详细注释：代码包含 JSDoc 文档注释与逻辑说明，便于复盘与理解
前端视角：结合前端业务场景解读算法思路，让刷题成果直接服务于开发能力
🛠️ 技术栈
JavaScript (ES6+)
Node.js（本地运行与调试）
VS Code（开发与调试工具）

| --- | --- | --- | --- |

📈 学习目标
通过系统刷题，掌握前端面试必备的算法思维，同时巩固 JavaScript 基础语法与数据结构，最终实现「算法能力」与「业务开发能力」的双向提升。
