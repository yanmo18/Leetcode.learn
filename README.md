# Leetcode.learn
> Leetcode 前端算法题解题学习笔记（JavaScript 版）

## 🎯 项目简介
本仓库是我作为前端开发者，系统刷 LeetCode 算法题的学习记录。所有题目均使用 JavaScript（ES6+）实现，重点聚焦前端面试高频算法考点，旨在通过刷题提升算法思维与代码能力，为前端岗位面试夯实基础。

## ✨ 核心内容
- **分类刷题**：按「数组/字符串/哈希表/双指针」等前端高频标签整理，覆盖前端面试 80% 以上的算法考点
- **多解法对比**：每道题提供「暴力解法」与「最优解法」（如哈希表），并详细分析时间/空间复杂度
- **规范注释**：代码包含 JSDoc 文档注释与核心逻辑说明，便于复盘和思路梳理
- **前端视角**：结合前端业务场景解读算法思路，让刷题成果直接反哺业务开发能力

## 🛠️ 技术栈
- JavaScript (ES6+)：优先使用 const/let、Map/Set 等现代语法
- Node.js：本地运行、调试算法代码
- VS Code：开发调试工具（配合 ESLint/Prettier 保证代码规范）

## 📈 学习目标
通过系统刷题掌握前端面试必备的算法思维，巩固 JavaScript 基础语法与数据结构知识，最终实现「算法解题能力」与「前端业务开发能力」的双向提升。
